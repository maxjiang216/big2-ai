# az_ii — imperfect-information net via perfect-information distillation (2026-06-12)

## What it is

Train an imperfect-information (II) Big 2 net by leveraging the perfect-information (PI)
series champion (`models/az_pi_series.pt` = gen4; see `az_pi_series_2026-06-12.md`), instead
of self-training an II net from scratch (the `az_search`/`model_az_seq` line plateaued on
value miscalibration).

**Net** (`nn/model_az_ii.py`, `Big2NetII`): the `model_az_seq` causal-transformer trunk over
the public move history, with the SAME scripted surface (`config`/`encode_prefix`/
`forward_leaf`/`readout` → value, policy, behavior, qa) so it drops straight into the existing
`az_search` MCTS / `NNEvaluator`. Adds:
- **AR opp-hand head** — GRU decoding rank counts high→low ([2,A,K,…,3]), per-rank masked
  softmax over counts 0..4 (bounds: `hi=min(thermo,remaining)`, `lo=max(0,remaining−tail_cap)`
  so samples sum to `opp_size`). Doubles as a belief **sampler** (determinization / stats).
- **P(bomb)** and **32-way outcome** (signed terminal-margin) heads.

These extra heads are training-time aux (jit-ignored); the search uses only value/policy/
behavior/qa.

**Data**: `az_pi_selfplay --distill-out` emits the games/player/opp triple (shared
`src/datagen/az_seq_record.h`) through the same `classify_position` head filter the search
queries; targets = the PI move actually played (one-hot cloning); value relabeled to series-V
in C++. `az_selfplay --no-explore` produces II self-play data noise-free (argmax move +
deterministic opp representative).

## Results (100 paired series, sims 100, series-sweep metric)

| variant | vs champion `az_seq.pt` | note |
|---|---|---|
| gen1 (PI-distill) policy-greedy | 0.39 per-game | no search |
| gen1 (PI-distill) + MCTS | 0.417 pg / 0.385 series | search ≈ no lift |
| gen2 (gen1 + II self-play) | 0.295 series | **regressed** |
| champion-bootstrap + aux | 0.480 pg / **0.470 series** | **~parity (tie)** |
| +aux vs −aux (champion base) | 0.510 series | **dead tie** |

**Conclusions.**
1. PI distillation alone → *below* champion: cloning PI moves yields over-aggressive play
   (the net imitates moves that are optimal *given perfect info*). PerfectDou §6.2 documents
   exactly this failure (reckless agents: high win% / negative ADP).
2. Naive II self-play fine-tune *regresses* — self-play games by gen1 agents are weaker than
   the PI teacher, so retraining overwrites the distilled policy downward.
3. **Bootstrapping from the II champion reaches parity** (start at the ceiling, not below).
4. **The aux heads are strength-neutral** (belief-AR / outcome as trunk regularizers add
   nothing; confirmed by both eval ties and near-identical train losses).

**Root cause of the ceiling**: an inference-time imperfect-information value can at best learn
`E[outcome | infoset]` = the average over all hidden opponent hands consistent with public
info. For contested positions that ≈ 0.5 → mushy leaf values → MCTS barely separates moves
("search ≈ no lift"). This is intrinsic to imperfect info; aux/search/more-distillation do not
fix it. A *sharper* value target (e.g. distilling the PI champion's perfect-info value) does
NOT help — fed to an imperfect-info-input head it just regresses to the same infoset average.

## Next idea — determinized value (and the strategy-fusion tradeoff)

The one principled, untested lever that attacks the mush directly. Use the AR belief head as
an **inference-time determinizer**, not a training aux.

Two ways to turn determinization into a value — they are NOT equivalent:
- **Average per-world *optimal* value**: sample opp hands from the belief, build each full
  perfect-info state, score with a perfect-info evaluator (we have one: the PI champion value
  / exact solver), average → `E_belief[V_PI(world)]`. **Sharp/discriminating, but carries
  strategy fusion**: it credits playing the world-optimal line in *each* world, as if the
  hidden hand were known — yet at one infoset only one action can be committed. Optimistic,
  biased.
- **Average the value of the single committed policy over worlds**: no strategy fusion, but
  equals `E[outcome | infoset]` = the mush. No gain.

**The unavoidable truth: escaping the mush requires accepting some strategy fusion.** The bet
is the PIMC bet — a discriminating (fused, optimistic) value beats a washed-out (unbiased) one
as a search signal. Empirically this pays in trick-taking games: **DeltaDou** (DouDizhu, MCTS +
Bayesian opp-hand determinization) reaches human level *with* fusion; PIMC dominates Bridge/
Skat. PerfectDou avoids fusion via PTIE, but DeltaDou shows the fused route is competitive.

We are well-equipped: AR head samples belief-consistent worlds; PI champion + exact solver
score them perfectly.

### Plan
1. **Cheap root-level probe first (no search integration).** At the real decision, for each
   candidate move: sample N (~32) determinizations from the AR belief, apply the move, score
   each resulting perfect-info state with the PI champion's value (and/or exact solver when
   shallow), average, argmax. Eval "determinized-value greedy" vs the champion (paired series).
   - **Decision gate**: if it clears parity, the fused signal is worth a full search build; if
     not, fusion bias ate the gain → stop or pivot to PerfectDou.
2. **If it clears**: fold determinized value into the MCTS leaf eval. Limit fusion damage —
   **fuse only in the value backup, keep one action per infoset** (visit counts pick the move;
   determinization only sharpens leaf value). Avoid per-world re-solving + per-world action
   selection (full fusion).
3. **Variant worth a cheap try**: skip own-value determinization; instead use the belief to
   **reweight the opponent-behavior priors** (better posterior over opp moves) — improves
   search opponent modeling with no fusion of our own value.

### Implementation sketch
- Reuse `ARHand.sample` (already exact: bounded, sums to `opp_size`).
- Perfect-info evaluator: load the PI champion (`pi_nn_eval`) or call the exact margin solver
  (`pi_solver`) for shallow worlds; both already in `src/players/az_pi/`.
- Root probe = a small standalone binary (or a flag on `eval_az_series`): drive a Game, at each
  az_ii turn run the determinized-value argmax above for player A, champion MCTS for player B.
- The belief net is `Big2NetII`'s AR head off the transformer hidden — already trained
  (AR 9.10 nats/row, beats masked-uniform baseline by 1 nat) and exported in the `.ts.pt`
  surface only as the scripted heads; the AR sampler is eager-only, so the probe runs the
  eager `Big2NetII` (load `models/az_ii_c.pt`) rather than the scripted net.

## Determinization probe RESULTS (2026-06-13)

Built `az_pimc` (root-only, no tree): dedicated belief net (`models/az_ii_belief.ts.pt`,
Big2NetII trained `--belief-only` on 20k champion no-explore self-play games, AR 9.45 nats /
ppx 2.07, beats masked-uniform ~0.66 nats) AR-samples N opp hands (γ=0.1 uniform-mixed,
scriptable `Big2NetII.sample_opp`); each legal move scored `1 − mean_i V_PI(opp=hand_i,
us=hand-after-move, trick=move)`; argmax. Registered `az_pimc` (param=N); plays as `--classic`
in eval_az_match/series. Metric = paired single-deal per-game win vs champion `az_seq.pt`
(100-sim MCTS). az_pimc win/game (champion = 1 − that):

| knob | az_pimc win/game | finding |
|---|---|---|
| N = 16 / 64 / 256 / 512 | 0.34–0.36, **flat** | NOT noise-limited → pumping N is useless |
| MoA vs AoM aggregator | 0.225 vs 0.233 (≈equal) | **strategy fusion NOT the issue** |
| PI eval = series net (pts 0,0) | **0.19** | wrong/flat target for single-game ranking |
| PI eval = game-value `az_pi.pt` | **0.36** | evaluator calibration is the DOMINANT lever (~2×) |
| policy-greedy az_ii (ref, 1-ply) | ~0.39 | det. ≈ distilled policy at equal depth |
| champion `az_seq.pt` (100-sim MCTS) | (it wins 0.64) | depth, not signal, is its edge |

**Decomposition (the asked question — fusion vs PI-OOD/calibration):**
1. **Fusion: ruled out.** Max-of-Average ≈ Average-of-Max. Committing one move then averaging
   vs per-world-argmax vote give the same result — the root-fusion bias is not what's hurting.
2. **Noise: ruled out.** Win rate is flat from N=16 to N=512. The determinized move *ranking*
   is stable, not sample-starved. (Kills the "variance caps the ceiling" hypothesis here.)
3. **Evaluator calibration: dominant.** Swapping the series PI net (fed pts 0,0 — a flatter,
   wrong target for single games) for a game-value PI net (`az_pi.pt`) roughly DOUBLED win rate
   (0.19 → 0.36). The determinized value is only as good as the PI evaluator's fitness for the
   actual objective. This is the PI-OOD/calibration axis, and it binds.

**Conclusion.** Properly fed, root-only (1-ply) determinization ≈ the distilled policy-greedy
(~0.36 vs ~0.39) and is signal-limited (flat in N), both far below the 100-sim champion. So at
equal depth determinization does NOT beat the policy — it matches it. The one untested lever
that distinguishes the champion is **search DEPTH**. The decomposition says: not fusion, not
noise → the gain (if any) must come from putting determinized value *in a tree* (plan step 2:
fuse only in the MCTS value backup, one action per infoset), OR the 1-ply ceiling is real and
the move is PerfectDou PTIE. Next decisive experiment = determinization-in-tree at matched sims
vs the champion.

Artifacts: `src/players/az_pimc/` (player+factory, env knobs PIMC_AGG=aom|moa, PIMC_PI_MODEL,
PIMC_PI_PTS), `Big2NetII.sample_opp` (scriptable AR sampler), `train_az_ii --belief-only`,
`models/az_ii_belief.{pt,ts.pt}`, data `data/pimc_belief_*`.

## Determinization-in-tree, Design 1 (2026-06-13)

`eval_az_match --det-pi models/az_pi.pt --det-n N` overrides **seat A's our-turn leaf VALUE**
with the determinized PI value (uniform belief from the leaf thermo, batch post-process on A's
leaf evals; `src/players/az_pimc/det_value.h`). Tree/PUCT/opp-expansion unchanged → one action
per infoset. Test: A = `az_seq.pt` + det leaf value vs B = `az_seq.pt` plain, matched 100 sims.

RESULT: **A 0.469 (Wilson [0.393, 0.546]), n.s. — no lift** (marginally worse). A/B diverge
(67/80 splits) so the override changes play; it just doesn't help. Sign verified (inverted →
~0.2, not a tie).

Caveats of this cheap cut: (1) UNIFORM belief, not AR; (2) only the **our-turn leaf value** is
replaced — opp-node values still come from the mushy `qa` head; (3) only the leaf scalar, not a
deep world-threaded tree.

**Caveat (1) KILLED (2026-06-13):** `--det-belief models/az_ii_belief.ts.pt` threads the full
history (game prefix + in-tree path) into the scripted `sample_opp`, γ=0.1 uniform-mixed
(`determinized_values_ar`). A=az_seq+det-AR vs B=plain, 100 sims: **A 0.481, n.s.** — vs uniform
0.469. AR belief does NOT rescue it. The our-turn leaf-value determinization is **neutral
regardless of belief quality**. Consistent with the perfect-info-AZ rule: once the policy is
good, value sharpness barely moves move-selection (PUCT is policy-dominated at 100 sims). Only
caveat (2)/(3) left = opp-node `qa` determinization + deep world tree = full Design 3 cost, low
prior after four negatives.

**Where determinization stands (three negative cheap results):**
- root 1-ply probe ≈ policy-greedy (~0.36), flat in N (signal- not noise-limited);
- aggregator MoA ≈ AoM (fusion not the issue);
- in-tree leaf-value swap ≈ plain champion (0.469, n.s.).

Consistent read: at these budgets, the determinized value (with a sharp PI evaluator) does NOT
beat the II net's own policy+search. The leaf-value mush is not the binding constraint — the
policy/visits already capture the move ranking. The only remaining higher-fidelity test is full
**Design 3 (FPMCTS/DeltaDou)**: AR belief threaded through the tree, opponent driven per-world,
**both** leaf value AND opp-node values determinized, deep world-threaded tree. Bigger build,
and with two cheap negatives the prior on success is lower. The documented alternative is
PerfectDou **PTIE** (perfect critic, no search, no fusion).

## Alternative — full PerfectDou paradigm
Drop MCTS; train the policy by imperfect-info self-play PPO+GAE with a **perfect-information
critic** (sees both hands, training-only, discarded at play). Avoids strategy fusion AND the
value mush (critic conditions on real hands; actor never does). Bigger rebuild (new training
loop, no search at inference), but the proven SoTA route for this exact problem.
